# 星火井冈 · 井冈山红色文化数字传播专题网站

> 巍巍五百里井冈——中国革命的摇篮。

一个以井冈山红色文化为主题的数字传播专题网站，纯静态页面，无需构建、无第三方依赖。

## 栏目内容

- **引言** —— 重读《井冈山的斗争》，探寻"红军为什么能在井冈山站住脚"
- **红色故事** —— 一根灯芯、"不拿群众一个红薯"
- **革命足迹** —— 井冈山革命博物馆、八角楼的灯光、大井旧居、小井红军医院、挑粮小道、朱德的扁担、黄洋界哨口
- **井冈山精神** —— 追寻红色足迹，聆听岁月回声
- **影像资料 / 互动答题** —— 视频展播与知识问答

## 本地预览

直接用浏览器打开 `index.html`，或在站点目录下启动任意静态服务器，例如：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 技术栈

HTML / CSS / 原生 JavaScript。
